# 防御塔、驻军与敌人肖像重制

2026-09-30，使用配置的 XEM Image API / gpt-image-2.5 生成。原始提示与完整参考图保留在本目录。运行时使用压缩后的本地 WebP，不依赖图片服务。

## 参考图与对应模型

- `towers-a.png`：每行四个造型，分别为一级、二级、两种三级专精。三行是箭塔（鹰眼 / 游侠）、法师塔（炎爆 / 奥术）、兵营（魔剑 / 圣骑）。
- `towers-b.png`：同样排列，三行是炮塔（迫击炮 / 魔力导弹井）、寒霜塔（暴风雪 / 冰川）、雷电塔（风暴电网 / 雷罚）。
- `soldiers.png`：四列为新兵、披甲卫士、蓝紫魔剑士、白金圣骑士；三行为正面、左侧、背面。
- `enemies.png`：上排为地精、狼族疾行兵、兽人破墙重兵、矮人铁甲卫兵；下排为符文构装体、沼泽蛙人、灰烬咒术师、暮翼石像鬼。

图标从参考图裁切，复现命令为 `python3 scripts/crop-combat-art.py`（需要 Pillow）。24 个建筑造型保存在 `public/art/towers/`，8 张敌人肖像保存在 `public/art/enemies/`。图鉴、遭遇情报、斥候已知敌人共用同一套肖像；未知波次仍显示问号。

模型由 `src/render/tower-models.ts` 与 `src/render/units.ts` 制作，使用实际三维几何，遵循参考图的配色、轮廓和装备。为远景辨识与性能简化了原画的微小砖纹和饰品；没有把图片当作场景内的平面模型。建筑静态几何按材质合并，浮动水晶单独保留，实例共享几何。士兵按关节合并，保留独立的行走、待机、攻击和施法姿态。

## 音效同步调整

`src/ui/sample-level.ts` 按实际播放片段的有效 30ms 窗口测量 RMS，忽略长静音与低于最大窗口能量 1% 的尾音，目标为 0.14 RMS，再应用原有事件权重。增益补偿上限 8 倍、单声部峰值上限 0.85；音乐、播放时刻与素材起音检测独立于响度校准。普通箭塔权重从 0.20（可选包）/ 0.22（基础包）调至 0.26，寒霜与雷电的普通释放声提升到 0.23。

攻击吼叫由 `CombatVoices` 管理：28% 概率，尝试之间至少 1.2 秒，同一类成功吼叫间隔至少 5 秒，全场吼叫至少间隔 1.8 秒。只管理地精、疾行兵、重兵、蛙人与石像鬼的攻击叫声；武器接触、法术与死亡声不受此概率限制。

没有新增音频来源或改变现有音频许可安排。可选 Mixkit / Pixabay 素材仍遵循 `docs/audio/` 中的本地资源包规则。
