# 艾莉娅 · 风翎

第一位英雄的造型与选择面板原型。森之精灵，17 岁，约 160 cm；高马尾金发、绿眼、弓箭与刺剑。白色布料与银色轻甲为主，绿色点缀；大腿长度短裙、白色过膝长袜、小腿中下段短靴。袜口与裙摆间留有短间隙。魔法羽翼由翠色风羽凝聚。

- [正常站姿立绘](aerilia-standing-final.png)：完整人体比例，简洁线条与大色块。
- [拉弓近景海报](aerilia-poster.png)：拉弓瞄准与展开光翼。

## 实现

`src/heroes/model.ts` 已重制为参考 YSM / Blockbench 表现方式的原创方块角色。保持艾莉娅既定的金发高马尾、精灵耳、白银与绿色服饰、短裙长袜、短靴、弓和刺剑；用较大的方块发束、倾斜刘海与四片裙甲明确轮廓，减少碎小几何。脸部采用代码绘制的 64 × 64 像素贴图及最近邻采样；不依赖外部模型或贴图库。

髋、躯干、头、肩、肘、手、腿、膝、马尾、披肩和光翼均为独立节点；弓使用独立武器挂点，通过左手掌心和背部挂点衔接。预览提供待机、行走、展翼和悬浮，光翼收起后隐藏；减少动态效果模式固定姿态。静态方块按关节实例化并以实例颜色保留配色，用于预览与战场共用模型。预览使用中性棚光与正交相机，支持正／侧／背面及放大查看。

现有立绘和“原设三视图”继续作为角色设定档案；它们不是新版模型实拍。普通士兵和敌人此次没有重制。

世界地图的关卡卡片提供英雄殿堂入口。可查看站姿立绘、拉弓海报、三视图与可旋转的体素模型，按关卡保存一位英雄的选择，支持取消携带。原生对话框提供焦点约束、Escape 关闭和返回焦点。禁用本地存储时仍可在当前会话选择。

英雄已接入局内：出征时携带艾莉娅，点击建造栏旁的英雄卡（H）后点击地面部署，Esc 取消。横持弓待机、拉弓和刺剑使用独立关节动作；远程对空对地、近身切换刺剑、脱战回血、阵亡复活。短距离地面寻路会拉直可通行路段，6 格以上自动展翼飞行并安全降落。近敌进入 2.8 格警戒区时主动上前接战，结束后返回驻守点。已加入出场、战败及施法动作，关节与朝向平滑过渡；贯风箭、翠羽箭雨和护身风暴自动按条件释放，带独立特效和冷却。第一／第三人称手操留待后续。

## 持弓动作校正 · 2026-09-30

- 备战待机横持弓于腰前，右手自然收在胸前；射击时髋部带动身体侧转、头部保持朝向目标，左臂伸展、右手拉至脸侧，弓立起，松弦后短暂保留随动姿势。
- 脱战 8 秒后收弓至背部；重新接敌先取弓，0.4 秒后才允许开始普通射击或弓箭技能。暂停同时暂停取弓和出箭时序。
- 拉弦、箭矢、左手握点使用实际关节位置。测试覆盖连续抬弓时弓弦与头部的间距、持弓握点、收取弓连续性以及中断射击。
- 动作参考：用户提供的实拍拉弓图和横持待机图；[World Archery 反曲弓说明](https://www.worldarchery.sport/sport/equipment/recurve)中“raise/draw → aim/execute → follow-through”的动作阶段。延伸阅读：[该页所列 Archery 360 教学视频](https://www.youtube.com/watch?v=08bv2eAugJM)。
