# 艾莉娅 · 风翎

第一位英雄的造型与选择面板原型。森之精灵，17 岁，约 160 cm；高马尾金发、绿眼、弓箭与刺剑。白色布料与银色轻甲为主，绿色点缀；大腿长度短裙、白色过膝长袜、小腿中下段短靴。袜口与裙摆间留有短间隙。魔法羽翼由翠色风羽凝聚。

## 最终参考

- [正常站姿立绘](aerilia-standing-final.png)：完整人体比例，简洁线条与大色块。
- [拉弓近景海报](aerilia-poster.png)：拉弓瞄准与展开光翼。
- [体素三视图](aerilia-voxel-final.png)：正面、侧面、背面。

以上通过用户配置的 XEM Image API / gpt-image-2.5 生成。对应提示词保存在本目录；早期造型迭代保存在 iterations/。立绘经历 standing-prompt 与 stocking-adjustment-prompt 两步，三视图经历 voxel-prompt 与 voxel-final-prompt 两步；海报使用 poster-prompt。最终运行素材为 public/art/heroes/ 下的 WebP，原始 PNG 仅用于美术存档。

## 实现

`src/heroes/model.ts` 以三视图的头身比例、马尾轮廓、服装分层、装备位置和配色为参考，构造实际 Three.js 模型：头发使用细阶梯体素，脸、四肢、布料与银甲使用有厚度的切面几何。按三视图重建了大眼睛与短下巴、弧形高马尾、连续披肩、褶裙、短靴、反曲弓、刺剑护手和箭袋。模型包含独立马尾和光翼节点，提供待机、展翼和悬浮预览；静态方块按材质实例化，减少绘制调用。预览使用中性棚光和正交相机，支持正／侧／背面及放大查看。美术三视图不是模型实拍，也不是自动重建结果。

世界地图的关卡卡片提供英雄殿堂入口。可查看站姿立绘、拉弓海报、三视图与可旋转的体素模型，按关卡保存一位英雄的选择，支持取消携带。原生对话框提供焦点约束、Escape 关闭和返回焦点。禁用本地存储时仍可在当前会话选择。

当前范围是英雄选择与外观预览；尚未生成战场英雄单位，弓箭、刺剑、飞行赶路的战斗逻辑留待下一阶段接入。
