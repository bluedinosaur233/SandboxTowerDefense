# 暮河守望 / Riverwatch

可改变地形的 3D 体素塔防，西幻边境山谷。当前为本地单机、五波完整战役，包含三张可切换地图。

## 核心闭环
准备防线 → 召来敌群 → 观察路线与防御 → 波次奖励 → 调整战场。守住城堡则胜，城堡生命归零则败。支持暂停、倍速和重新开始。

## 规则
- 体素格使用 x/z 平面坐标与离散海拔。四方向寻路考虑坡度、涉水及破坏建筑的时间成本。
- 墙并非不可穿越障碍：敌人到达前会攻击；水道可以通行但会显著减速。修改地形或建筑摧毁后更新路径。
- 防御塔按炮口与敌人中心的三维欧氏距离检测球形范围。高台可改变覆盖，但不会自动增加射程。
- 箭塔快速物理攻击；法师塔魔法范围攻击；炮塔物理范围攻击；寒霜塔减速；雷电塔连锁。兵营维持小队，自动拦截附近敌人，阵亡后补员。
- 地形工具包括挖水道、抬高土地和搭建木桥；桥梁可拆除恢复水道。地形编辑不能覆盖城堡、出生点或单位。
- 七类敌人：林地地精、荒野疾行兵、破墙重兵、铁甲卫兵、符文卫士、沼泽潜行者、灰烬咒术师。各有独立体素外观、属性与克制关系。

## 地图

- **暮河山谷 / river**：基础河谷，河流、涉水减速和木桥组成第一张教学战场。
- **霜脊高地 / mountain**：盘山古道从山麓上升到霜冠要塞，海拔范围为 2–22；路线长、平台多，适合用高差观察三维射程。
- **风裂悬桥 / canyon**：西崖与东崖之间是不可通行的深谷，南北两条吊桥是主要路线。吊桥可以逐格搭建或拆除；拆除一座会让敌军改道，拆除第二座会因唯一通路保护而失败。

地图选择器会同步更新章节标题、目标、入口与要塞标签、初始建筑、波次名称和相机中心。每张地图仍共享同一套建筑、经济、敌军和地形编辑规则。

## 工程
TypeScript + Vite + Three.js。模拟状态与渲染分离，固定时间步推进。程序化体素几何与本地打包的 UI 插画，无运行时远程素材或账号依赖。相机为可旋转/平移/缩放的正交俯视相机。UI 使用 DOM，地图使用 WebGL。

- 升级改变建筑几何轮廓，3D 球面射程显示球壳和逐高度地表切片。
- 背景音乐使用 Kevin MacLeod 两首 CC BY 4.0 本地音频；音效使用 22 个本地 CC0 采样，支持音量、音乐切换、空间声像和重复限制。
- WASD 按当前镜头方向移动。

## 验证
寻路绕墙/破墙、涉水减速、坡度代价、球形射程、兵营阻挡、波次胜负使用自动化测试；浏览器验证建造、相机、工具提示、暂停、重开、响应式布局和实际 WebGL 画面。

## 大陆选关界面

入口为尺度 900 × 648 的程序化体素大陆，十二片疆域以不规则的河流、湖泊、山麓、峡湾和海岸过渡。参考图见 `docs/art/greater-continent-reference.png`；实际运行时依照参考图的地貌布局构建 Three.js 体素地形。地形按 600 × 432 个网格构建，体素边长 1.5、垂直分层 0.75，只生成顶部与外露侧面；树木、聚落和地标采用稀疏实例化几何；火山有熔岩台阶与烟柱，湿地有遗迹与芦苇，沙海有阶梯古墓与绿洲，群岛有港湾和灯塔。大陆支持拖动、缩放、全览与触屏手势；区域探索会提高镜头倍率，优先聚焦该地区首府。地表颜色、植被和海拔采用独立的宽过渡带，保留真实河岸和海崖，避免用整块高台表示生态区边界。

三个现有关卡对应地图上的可选旗帜，出征前显示简短地形与波次信息。非关卡疆域仍然完整绘制并可从「疆域图志」飞行查看，不因为当前没有可玩地图而省略地形；仅关卡旗帜对应出征。结果页支持返回大陆，最高通关星级写入浏览器本地存储；加载时忽略无效数据，存储不可用时仍能在当前会话游玩。

## 敌军与伤害系统

物防与法抗均为百分比，只作用于对应伤害类型。实际伤害 = 原始伤害 × (1 − 对应减伤率 / 100)，内部保留小数。箭塔和卫兵造成物理伤害；法师塔造成魔法范围伤害，范围内每个目标分别结算法抗。敌军攻击同样区分物伤与法伤，建筑和卫兵也有防御属性；寻路中的破墙时间按减伤后的伤害估算。城防损失是敌人突破后的固定惩罚，独立于战斗减伤。

第 1 波为基础地精与疾行兵；第 2 波引入高物防和地图特色兵种，第 3 波加入重兵和符文卫士，第 4 波出现咒术师，第 5 波混编全部兵种。每波数量为 8 + 波数 × 4，生命每波增加基础值的 12%，其他敌军属性不随波次膨胀。这是首版平衡参数，仍需根据实际通关数据调整。

卫兵初始物防 20%、法抗 10%；高等级兵营新招募卫兵的物防每级增加 5 个百分点。石墙物防 20%、法抗 0%，箭塔 10%/0%，法师塔 5%/25%，兵营 15%/10%。建筑升级主要沿用耐久与火力提升。

图鉴在世界地图与战场工具栏均可打开。可预览全部条目，但只有实际生成的敌人才计入已遭遇。首次遭遇发出可点击、可稍后阅读的情报卡，不强制中断战斗；打开图鉴暂停战斗，关闭后恢复原先暂停状态。已遭遇种类和未读情报存入 `riverwatch.bestiary.v1`，跨关卡、刷新与重开保留；存储不可用时保持会话内记录。多个新敌人按顺序提示，阅读一个不会清除其他未读情报。

## 防御塔与三级专精

一级 → 二级为常规升级，伤害提高 55%、射程增加 0.6 格、攻击间隔除以 1.1；二级 → 三级必须选择该塔的一种专精，不可再切换。每次升级恢复耐久，并将最大耐久乘以 1.4。兵营和石墙沿用三级常规升级；拆除只返还基础造价的一半，不返还升级投入。

爆炸、射程与连锁跳跃均计算三维距离，连锁不重复命中同一个目标，每个目标独立结算防御。穿透与破甲按百分点相减，最低减伤率为 0%；破甲在本次命中伤害结算后生效，后续箭矢、炮弹和卫兵攻击均受益。伤害与效果在发射时快照，升级不会强化已经发出的弹丸。

减速、灼烧、破甲各自取当前最强值；同强度重复命中刷新持续时间，弱效果不会延长强效果，强效果结束后后续命中可施加新状态。减速不改变敌人攻击频率，并与涉水减速相乘。冻结 / 麻痹阻止移动和攻击；灼烧单独受法抗减免，击杀沿用一次性奖励流程。选中敌人可查看当前异常状态和被削减后的物防。

建造栏分为防御塔和地形工事，保留原数字 1–7，新增 8 炮塔、9 寒霜塔、0 雷电塔。分支面板显示攻击数值、效果与三类资源费用，资源不足禁用购买；打开暂停战斗，关闭恢复原状态。
