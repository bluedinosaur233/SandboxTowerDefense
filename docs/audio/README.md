# 本地战斗音效包

2026-09-30：从 Pixabay 的 5 条、Mixkit 的 15 条素材制作 26 个短采样（含历史对比版本），当前替换 46 个事件。英雄弓弦、箭矢入体、刺剑、飞行、技能与入场/战败分别配置；元素魔法、魔剑士、圣骑士和炮弹命中也已替换。音乐保持原配置。

来源、作者、原始下载 SHA-256 和逐条剪辑参数见 [licensed-pack.json](licensed-pack.json)，授权说明见 [LICENSED-CREDITS.md](../../public/audio/LICENSED-CREDITS.md)。这是两个网站的自定义许可，不是 CC0。Mixkit 不允许将音频随源文件重新分发，Pixabay 不允许独立素材分发，因此 `public/audio/licensed/` 和原始下载所在的 `work/` 已忽略。它们可以作为游戏的一部分进入本机的 `dist/` 试玩构建；不要将这些文件单独作为素材包发布。

## 在另一台开发机恢复

1. 从配方中的来源页面下载原文件，按 `sources` 中的 `file` 命名，放进 `work/audio-sources/`。优先在浏览器正常下载；Pixabay 没有配置直接下载地址。
2. 给 Python 环境安装 `numpy`、`soundfile`，运行 `python3 scripts/prepare-licensed-audio.py`。脚本先核对所有原文件 SHA-256，再生成 WAV 和本地 `pack.json`，不会联网下载。
3. `npm run dev` 或 `npm run build`。本机打包会包含已准备的声音，开公网试玩也使用这份本地包。

缺少整个包时使用原有 OpenGameArt / Kenney 采样。某个新采样加载失败时，仅对应事件回退，其他新采样正常使用；音效设置会报告加载失败。游戏运行期间不会访问素材网站，也不需要代理。

## 验证与试听

`npm test` 覆盖替换加载、缺失回退、即时播放和伤害/命中同步。本机开发环境若保留了 `audio-review.html`，运行 `npm run dev` 后可打开该页面（不随源码发布），可以听实际播放器中的英雄普攻、箭雨、魔法与炮弹声音；试听页不播放背景音乐。它只用于开发试听，不是游戏内新增菜单。

剪辑去掉了弓弦开头静音、箭矢接触前的气流，以及迫击炮素材约两秒的下落前奏。采样以事件时间立即播放，不额外排队。音色的最终适配仍以实际游戏听感为准。

## 英雄弓箭二次调整

按“自然弓弦与入体感，带少量风魔法”的反馈，新增 `hero-bow-wind` 与 `hero-arrow-soft`。弓弦取自实录 Arrow Release and Hit 的 0.304–0.487 秒，截断在第二次接触声之前；风尾音在 22 ms 后叠入，峰值层权重 12%。命中改用 Arrow Hit，削弱低频与硬质高频，加入 6.5% 的短气流层；英雄命中增益从 0.29 降至 0.20。箭雨沿用新版接触声，弩塔和普通箭塔的音色配置不变。试听页底部保留上一版弓弦、命中素材。

## 英雄射出恢复最早版

根据后续反馈，英雄普通射击恢复 `swing-2.wav`，完整沿用初版增益 0.24、速率 0.95、最长 0.5 秒；可选素材包不再覆盖这一事件。命中独立试用 `hero-contact-dry`：取实录 Arrow Release and Hit 的第二个接触段（0.496–0.686 秒），不叠加风声，英雄命中增益 0.16。箭雨使用同一接触片段，增益 0.12。先前的弓弦/命中保留在试听页作对比，不作为英雄普攻候选随机播放。


## 箭塔可听度调整

普通箭塔和游侠连弩的可选采样改为 Mixkit 2771 `Arrow shot through air`，运行文件 `tower-arrow-release.wav`。取 0.095–0.385 秒的发射主体，避免前奏延迟与长尾占用声音通道；普通箭塔事件增益由 0.26 提至 0.46（约 +5 dB），连弩为 0.40。无许可包时的默认声音也使用相应增益。新的声音通过既有起音检测、响度校准与峰值限制播放，英雄的初版发射音保持原配置。

`audio-review.html` 增加箭塔单次发射、连续发射、命中组合及连弩试听按钮，调用实际游戏播放器。


## 雷罚尖塔可听度调整

单体分支使用独立 `judgment-strike.wav`：Mixkit 2599 重型电击主体，叠加 2600 放电瞬态，剪为约 0.51 秒。事件增益从 0.38 提高到 0.58（约 +3.7 dB），不再降速复用普通命中声。缺少本地包时使用已有 CC0 `thunder-burst.wav`。雷罚允许使用普通音效上限之外的两个通道，仍为英雄／首领／界面保留额外四个通道，避免 18 个普通音效同时播放时直接丢弃雷罚声。命中音仍由真实命中事件触发。

试听页增加雷罚单发和按 2.2 秒攻击间隔的连续演示。
