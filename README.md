# 暮河守望 · Riverwatch

一个可直接在浏览器游玩的 **3D 体素西幻塔防原型**。用石墙、水道、高地、防御塔和卫兵改变敌军的进攻方式，并在三张地形差异明显的战场之间切换。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。当前开发服务器使用 `http://127.0.0.1:5173/`。

```sh
npm run build   # 类型检查与生产构建，输出 dist/
npm run preview
npm test        # 模拟、镜头、射程、桥梁、血条和音效测试
npm run test:browser  # Chrome 真实浏览器试玩，先启动开发服务器
```

浏览器测试默认使用 Playwright 自带的匹配 Chromium；在允许浏览器启动的环境中，可通过 `CHROME_PATH` 指定可执行文件。测试使用临时浏览器资料目录。

## 已实现

- 42 × 32 格立体战场，支持三张地图：暮河山谷、霜脊高地、风裂悬桥。地图选择会同步切换入口、要塞、初始建筑、波次名称、相机高度与地形规则。
- 霜脊高地使用盘山古道和 2–22 级阶梯高差；风裂悬桥使用深谷与两条预置吊桥，拆除一座后敌军会转向另一座，唯一通路不能被拆断。
- 石墙可迫使敌军绕路，也可被敌军拆毁。木桥可以在水道上逐格搭建，也能拆除恢复水道；寻路成本考虑行走、坡度、涉水、破墙耗时。
- 挖河：降低一层地形并转为水道，普通敌军涉水速度降到 38%，疾行兵为 65%，重兵为 30%。
- 筑高地：每次抬升一层，最高海拔由地图决定。两格之间海拔差超过 2 时无法通行；会封死所有路线的修改不会扣费。
- 箭塔与法师塔按三维欧氏距离索敌，选中或建造时显示真实球形射程。法师塔带溅射伤害。
- 兵营自动训练卫兵，接敌后近战阻挡。升级增加队伍人数；战斗中每 9 秒补员。
- 金币、木材、石料；波次补给、建筑升级、拆除返还基础造价的 50%（向下取整）。
- 地精、疾行兵、破墙重兵，完整五波战役、胜负结算、重开、暂停、1/2/3 倍速。
- 中文 HUD、操作说明、路径显示、正交相机、响应式布局。战地面板采用木框、黄铜与羊皮纸的西幻指挥界面。
- 箭塔 / 法师塔升级会替换模型几何与轮廓：二级增加石砌结构，三级增加塔楼、旗帜和奥术环。
- 选中防御塔可同时看到球面等距线与射程球和不同海拔地表的交线覆盖面。高处被球面切除的覆盖区会显现。
- 敌军、卫兵和建筑只在受伤后短暂显示简洁血条，3 秒后淡出；血条逐帧固定跟随头顶，不做避让位移。巡视模式点击单位或建筑，在信息面板查看生命值和详情。
- 路径重算保留单位当前前进的格边，避免取整回到身后格心造成折返。
- WASD 根据旋转后的当前镜头方向移动相机。
- 本地音乐：《Skye Cuillin》（竖琴、哨笛、提琴，凯尔特／神秘氛围）和《Ascending the Vale》（牧歌竖琴、合唱与长笛）。可切曲、分开调节背景音乐和音效音量，设置写入本地浏览器。
- 22 个本地 CC0 采样覆盖箭矢、法术、命中、近战、撞墙、倒塌、死亡、招募、渡水、城堡受击、升级和波次反馈；空间声像随相机方位变化，并限制短时间重复音。来源与授权见 [音效授权说明](public/audio/sfx/CREDITS.md)。
- 音乐作者署名和 CC BY 4.0 许可见 [音乐授权说明](public/audio/music/CREDITS.md)。

## 操作

| 操作 | 输入 |
| --- | --- |
| 选择工事 | 点击底部工具栏，或数字 1–7 |
| 建造 / 选择建筑 | 左键点击地块 |
| 巡视 / 关闭说明 | Esc |
| 搭建木桥 | 7，然后点击水面；每格 12 金币、12 木材 |
| 拆除工具 | X（建筑或木桥，包含地图原有桥梁） |
| 开始下一波 | Enter / 吹响号角 |
| 暂停或继续 | Space |
| 旋转视角 | 按住右键拖动 |
| 平移 | 按住鼠标中键拖动，或 WASD（按当前镜头朝向移动） |
| 缩放 | 滚轮 |
| 重置视角 | R / 左下角罗盘 |
| 触屏 | 点按建造、单指拖动平移、双指缩放与旋转 |
| 音乐与音效设置 | 右上角音符按钮，可切曲、分别调音量 |

初始放置了一座箭塔、一座法师塔、一座兵营和三段墙，方便立即观察核心机制。推荐在暮河先用水道和墙引导敌军，在霜脊占住高差平台，在风裂悬桥优先保护或拆除关键桥格。

## 工程结构

- `src/simulation/game.ts`：纯 TypeScript 模拟、寻路、经济、单位与波次。
- `src/render/world.ts`：Three.js 场景、体素几何、建筑等级轮廓、相机、拾取和特效。
- `src/render/range.ts`：球形射程外壳、交线与地形覆盖 shader。
- `src/render/camera-motion.ts`：镜头相对平移。
- `src/main.ts`：界面交互、固定 30 Hz 模拟时钟和渲染循环。
- `src/ui/`：SVG 图标、音乐混音控制与本地采样音效。
- `public/audio/sfx/`：22 个本地 CC0 音效采样、来源、授权和 SHA-256 清单。
- `public/audio/music/`：本地打包音乐与作者署名。
- `tests/simulation.test.ts`：寻路、射程、建造、兵营与胜负规则测试；`tests/presentation.test.ts` 覆盖升级轮廓、镜头方向、射程切片和音频事件。
- `scripts/browser-smoke.mjs`：真实点击建造、升级、相机、战斗、结算和手机布局验证。
- `docs/DESIGN.md`：设计边界及后续功能候选。
- `docs/art/riverwatch-ui-reference.png`：UI／美术方向参考图。
- `docs/art/mountain-map-reference.png`、`docs/art/canyon-map-reference.png`：新增地图的概念设定参考图；它们用于确定色彩、构图和地形识别，实际运行时仍使用 Three.js 程序化体素绘制。

体素模型和地形工具图标为程序化几何，四类建筑按钮使用本地打包的生成插画，来源与裁切记录见 [美术说明](docs/art/README.md)。运行时不依赖远程美术素材，也不请求外部字体。当前尚无存档、科技树或联网功能；重启/刷新会重置当前地图战役。
