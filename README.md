# 暮河守望 · Riverwatch

一个可直接在浏览器游玩的 **3D 体素西幻塔防原型**。用石墙、水道、高地、防御塔和卫兵改变敌军的进攻方式，并在大陆上的战役据点逐步推进。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。当前开发服务器使用 `http://127.0.0.1:5173/`。


```sh
npm run build   # 类型检查与生产构建，输出 dist/
npm run preview
npm test        # 模拟、镜头、射程、桥梁、血条和音效测试
npm run test:browser  # Chrome 真实浏览器试玩，先启动开发服务器
```

浏览器测试默认使用 Playwright 自带的匹配 Chromium；在允许浏览器启动的环境中，可通过 `CHROME_PATH` 指定可执行文件。测试使用临时浏览器资料目录。

本仓库包含可再分发的备用音效。Mixkit / Pixabay 可选音效包不随源码上传；如需使用，按[音效准备说明](docs/audio/README.md)自行下载并在本地生成。

## 世界地图与选关

游戏从可拖动、缩放的 3D 世界地图开始。尺度为 900 × 648 的大陆以 600 × 432 网格绘制，包含十二片疆域：霜脊雪山、碎冰峡湾、翡翠密林、暮河原野、紫雾湿地、镜湖盆地、白垩海崖、金叶丘陵、风裂断崖、琥珀沙海、烬火群峰与碧潮群岛。河流、湖泊、火山、熔岩、瀑布、村庄、石环、古墓、吊桥和灯塔组成一整块连续大陆；大陆外铺设带浅海陆架、岸线泡沫和动态波纹的海面，岩岸延伸至海面以下。地区之间以林草混合带、山麓、沙化坡地和湿地边缘过渡。

默认以更近的镜头展示大陆，不自动选中关卡。点击地图旗帜才展开羊皮纸面板，查看实际地形缩略图、关卡简介并选择随行英雄；点击空白地图或关闭按钮收起。点击「出征」后，面板收起，镜头推近关卡位置并穿过云雾下降至战场（约 3.25 秒）；系统开启减少动态效果时改用短淡入淡出。当前可玩风渡前哨；其余疆域是可自由探索的大陆景观，暂不绑定独立战斗关卡；主界面的「疆域图志」可以飞往任意区域查看地标与传说。大陆有 11 座地区首府和 24 处外围聚落，建筑随地貌采用山口堡垒、林间尖塔、高脚木镇、砂岩院落或海港等风格；烬火群峰不设常住聚落。选择疆域会优先聚焦首府，放大后显示城名。战斗中点击右上角「世界地图」会暂停当前战役，可通过「继续当前战役」返回。再次出征会重开所选关卡。

通关后按剩余城防记录星级：100 城防为 3 星，50–99 为 2 星，1–49 为 1 星。三星通关且携带的英雄全局未阵亡时，三颗金星会依次获得蓝粉星辉镀层。最高星级保存在当前浏览器，刷新后保留；战斗中的建筑和波次不保存。

## 已实现

- 100 × 80 格范围内的不规则河谷战场：圆缓山脊、低地河流、要塞高台与三处延伸入口组成自然边界；草地、河岸和高处岩面以连续色带过渡。风渡前哨位于主地图暮河原野通往镜湖的旧渡口，西岸、北坡和东南三路会在不同波次加入进攻。
- 中央要塞外有西岸麦田与北坡银矿两个生产据点，出生点距据点至少 26 格。准备阶段可重建、修缮和扩建；战中两次运回金币，守住后获得丰收金币，连续守住会增收。失守会丢失丰收、连守加成和扩建等级。
- 石墙可迫使敌军绕路，也可被敌军拆毁。木桥可以在水道上逐格搭建，也能拆除恢复水道；寻路成本考虑行走、坡度、涉水、破墙耗时。
- 挖河：降低一层地形并转为水道，普通敌军涉水速度降到 38%，疾行兵为 65%，重兵为 30%。
- 筑高地：每次抬升一层，最高海拔由地图决定。两格之间海拔差超过 2 时无法通行；会封死所有路线的修改不会扣费。
- 五类攻击塔：箭塔、法师塔、炮塔、寒霜塔、雷电塔，分别提供箭矢、魔法爆炸、物理爆炸、减速与连锁攻击。按三维欧氏距离索敌，普通炮塔仅对地，使用朝向锥形射界；迫击炮全向攻击且有盲区，魔力导弹井可以对空。范围显示与索敌使用同一三维判定。
- 兵营自动训练卫兵，接敌后近战阻挡。一级 2 人，二级和三级专精均为 3 人；战斗中阵亡后每 15 秒补员一人。
- 单一金币经济：击杀赏金、固定波次补给与据点收入；建造和升级明示金币价格、拆除返还基础造价的 50%（向下取整）。15 波经济已重新平衡，降低后期赏金与生产滚雪球，提高升级投入；完整数值见设计文档。
- 八类基础敌军、三种精英和首领「碎冠者·格罗姆」；完整十五波战役、首领预警与独立血条、胜负结算、重开、暂停、1/2/3 倍速。
- 中文 HUD、操作说明、斥候报告、正交相机、响应式布局。战地面板采用木框、黄铜与羊皮纸的西幻指挥界面。
- 五类攻击塔均可先升二级，再从两条三级专精中二选一，共十种专精；各等级与分支均有独立模型轮廓、弹道和战斗效果。
- 选中防御塔可同时看到球面等距线与射程球和不同海拔地表的交线覆盖面。高处被球面切除的覆盖区会显现。
- 敌军、卫兵和建筑只在受伤后短暂显示简洁血条，3 秒后淡出；血条逐帧固定跟随头顶，不做避让位移。巡视模式点击单位或建筑，在信息面板查看生命值和详情。
- 每个敌人独立选择目标与路径：地精、疾行兵和符文卫士优先要塞；重兵、铁甲卫兵和咒术师优先防御建筑；潜行者优先生产据点。不同兵种会权衡火力、涉水、坡度与破墙成本，目标消失后重新选择。
- 不再显示固定路线箭头。号角旁的斥候来报与入口旗帜可查看当波各方向的兵种和数量，未遭遇兵种显示「？？？」。
- 路径重算保留单位当前前进的格边，避免取整回到身后格心造成折返。
- 小屏 HUD 将左侧任务说明收为状态行，压缩波次面板；经济建筑标签仅在悬停、选中或短暂入账时出现，可从顶部「领地经济」查看与切换据点。离开视野的入口提示带有指向真实入口的箭头。
- WASD 根据旋转后的当前镜头方向移动相机。
- 兵营可升级为蓝紫色魔剑士或白金色圣骑士；升级同步换装并保留现役士兵的生命比例，后续补员沿用分支。士兵按实际位移播放步行动作，驻守和暂停时保持静止。
- 魔法战斗音效采用能量、冰裂、电击和气流素材；爆炸采样从冲击起点播放。炮弹、法弹、箭矢及英雄箭雨的命中效果与音效共用战斗时间。
- 6 首本地凯尔特／中世纪配乐，主地图和战场分别轮播，首次点击后启奏，切曲淡入。主地图「暮河的乐声」与战场音符按钮可切曲、调节音乐／音效音量。
- 完整配乐使用 64 kbps AAC（M4A），提前缓冲并限制音效并行下载；屏幕上方显示音乐缓冲状态和音效加载进度，失败时可点击重试，准备就绪后自动收起。
- 本地 CC0／CC BY 采样，分别配置五类塔与十条专精分支、八类怪物，以及英雄的弓箭、刺剑、飞行、出场、战败与三种技能；空间声像随相机方位变化，并限制短时间重复音和同时发声数。来源与授权见 [音效授权说明](public/audio/sfx/CREDITS.md)。
- 音乐作者署名和 CC BY 4.0 许可见 [音乐授权说明](public/audio/music/CREDITS.md)。

- 首领出场使用独立运镜、落锤与落地动作，举锤和狂暴配合战吼；击败后倒地，血条先退场，再收起战斗界面并播放胜利与星级结算。失败也有独立退场和结算流程。

## 操作

| 操作 | 输入 |
| --- | --- |
| 选择建造卡牌 | 切换「防御塔 / 地形工事」分页，数字键按当前页从左到右选择 |
| 防御塔快捷键 | 1 箭塔、2 法师塔、3 兵营、4 炮塔、5 寒霜塔、6 雷电塔 |
| 升级 / 专精 | 巡视时点击防御塔；升至二级后点击「选择三级专精」 |
| 建造 / 选择建筑 | 从卡牌栏拖出后松手，预览跟随鼠标，再点击建造；也可先点击卡牌 |
| 建筑朝向 | Q / E 逆时针 / 顺时针；备战期选中指向型建筑后可自由瞄准，战斗中锁定 |
| 工事延伸 | 仅地形工事：点击四邻虚影接着建，点击其他位置退出 |
| 巡视 / 关闭说明 | Esc |
| 搭建木桥 | 地形工事页按 4，选择水面并确认；价格以建造卡牌为准 |
| 拆除工具 | X（建筑或木桥，包含地图原有桥梁） |
| 开始下一波 | Enter / 吹响号角 |
| 暂停或继续 | Space |
| 旋转视角 | 按住右键拖动 |
| 平移 | 左键 / 中键拖动或 WASD（按当前镜头朝向移动）；Shift 加速 |
| 缩放 | 滚轮 |
| 重置视角 | R / 左下角罗盘 |
| 触屏 | 点按建造、单指拖动平移、双指缩放与旋转 |
| 音乐与音效设置 | 右上角音符按钮，可切曲、分别调音量 |

初始放置箭塔、法师塔、兵营和中央墙段，方便观察三路布防。推荐先修复一个生产据点，再根据下一波情报决定扩张、补塔或放弃外围。

## 工程结构

- `src/simulation/game.ts`：纯 TypeScript 模拟、寻路、经济、单位与波次。
- `src/simulation/towers.ts`：五类攻击塔、十种专精与统一攻击参数。
- `src/render/world.ts`：Three.js 场景、体素几何、建筑等级轮廓、相机、拾取和特效。
- `src/render/range.ts`：球形射程外壳、交线与地形覆盖 shader。
- `src/render/camera-motion.ts`：镜头相对平移。
- `src/campaign/`：世界地图地貌、体素场景、选关界面和本地星级进度。
- `src/main.ts`：界面交互、固定 30 Hz 模拟时钟和渲染循环。
- `src/ui/`：SVG 图标、音乐混音控制与本地采样音效。
- `public/audio/sfx/`：本地 CC0／CC BY 音效采样、来源、授权和 SHA-256 清单。
- `public/audio/music/`：本地打包音乐与作者署名。
- `tests/simulation.test.ts`：寻路、射程、建造、兵营与胜负规则测试；`tests/presentation.test.ts` 覆盖升级轮廓、镜头方向、射程切片和音频事件。
- `scripts/browser-smoke.mjs`：真实点击建造、升级、相机、战斗、结算和手机布局验证。
- `docs/DESIGN.md`：设计边界及后续功能候选。
- `docs/art/riverwatch-ui-reference.png`：UI／美术方向参考图。
- `docs/art/mountain-map-reference.png`、`docs/art/canyon-map-reference.png`：早期关卡概念参考，作为美术档案保留；当前可玩关卡已替换为风渡前哨。

体素模型和地形工具图标为程序化几何，四类建筑按钮使用本地打包的生成插画，来源与裁切记录见 [美术说明](docs/art/README.md)。运行时不依赖远程美术素材，也不请求外部字体。当前保存通关星级、英雄编队和敌人图鉴记录，尚无战斗存档、科技树或联网功能；重启/刷新会重置当前地图战役。

### 敌军情报与伤害类型

现有 8 种基础敌人、3 种精英和 1 名首领，均接入十五波战役。物防减免物理伤害，法抗减免魔法伤害：箭塔与卫兵克制高法抗敌军，法师塔克制高物防敌军。点击单位或建筑可查看防御与攻击类型。

在世界地图或战场顶部点击书本图标打开敌人图鉴。每次出征时，每类敌人在本关首次登场都会出现可点击情报，重玩也会再次提示；阅读时自动暂停，关闭后恢复原状态。图鉴发现记录保存在当前浏览器，关内提示独立计算，不受上次游玩记录影响。完整数值与公式见 [设计文档](docs/DESIGN.md)。

### 防御塔与升级分支

| 基础塔 | 三级专精 A | 三级专精 B |
| --- | --- | --- |
| 箭塔 | 鹰眼长弓塔：远射、穿透物防 | 游侠连弩塔：快速同时攻击三个目标 |
| 法师塔 | 炎爆法师塔：大范围爆炸、持续灼烧 | 奥术棱镜塔：单体重击、穿透法抗 |
| 炮塔 | 高地迫击炮：全向对地，10 格射程、2.2 格近身盲区 | 魔力导弹井：全向对地 / 对空，范围法伤并削弱物防 |
| 寒霜塔 | 暴风雪塔：群体减速 | 冰川禁锢塔：单体冻结、强力减速 |
| 雷电塔 | 风暴电网：最多连击五名敌人 | 雷罚尖塔：单体雷击、短暂麻痹 |

选定专精后不可切换。选择面板会展示两种分支的攻击、射界、对空能力、特效和金币价格，查看时暂停战斗。所有伤害继续按物防 / 法抗结算；同类状态不相乘叠加。炮弹爆炸与闪电跳跃也计算高度差。

新增工事：木栅栏（3 金币、75 耐久）、尖刺陷阱（20 金币、12 物伤/秒、地面敌军减速 35%）、石板路（4 金币、卫兵移速 +35%）、平整地形（5 金币、陆地降低一层）。预览不扣费，确认时再次校验；地形修改仍需保留合法通路。新增图标由 XEM / gpt-image-2.5 生成并裁切为本地透明 PNG。
